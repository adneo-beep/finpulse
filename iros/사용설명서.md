# 상업용 대출 만기심사 자동 조회 루틴

정부 공공사이트 6곳에서 부동산 관련 정보를 자동으로 조회·캡처하여 Word 문서로 저장하는 자동화 프로그램입니다.

---

## 📋 조회 항목

| # | 항목 | 사이트 |
|---|------|--------|
| 1 | 상가 기준시가 | 국세청 홈택스 |
| 2 | 매각가율 | 법원경매정보 |
| 3 | 사업자등록상태 | 국세청 홈택스 |
| 4 | 토지이용계획 + 건축물정보 | 토지이음 |
| 5 | 지가변동률 | 한국부동산원 |
| 6 | 개별공시지가 | 부동산공시가격알리미 |

---

## 🖥️ 사전 준비 (최초 1회만)

### 1. Node.js 설치
- https://nodejs.org 접속 → **LTS 버전** 다운로드 및 설치
- 설치 확인: 명령 프롬프트(cmd) 열고 아래 입력
  ```
  node --version
  ```
  버전 번호가 나오면 설치 완료

### 2. 프로그램 폴더에서 패키지 설치
- 명령 프롬프트(cmd)를 열고 프로그램 폴더로 이동
  ```
  cd "C:\Users\사용자명\프로그램폴더"
  ```
- 아래 명령어 실행 (최초 1회)
  ```
  npm install
  npx playwright install chromium
  ```

## 🚀 사용 방법

### 1단계: 입력 파일 작성

`input-template.json` 파일을 복사해서 파일번호에 맞게 이름을 바꾸고 내용을 수정합니다.

예) `111.json` 파일 내용:
```json
{
  "파일번호":        "111",
  "시도":           "부산광역시",
  "시군구":          "강서구",
  "읍면동":          "명지동",
  "본번":           "3232",
  "부번":           "",
  "건물명":          "영어도시퀸덤1차",
  "건물동":          "322동",
  "층":             "지하1층",
  "호":             "317호",
  "사업자등록번호":   "4823100133"
}
```

#### 입력 항목 설명

| 항목 | 설명 | 예시 |
|------|------|------|
| 파일번호 | Word 파일명으로 사용 (111 → 111.docx) | `"111"` |
| 시도 | 시·도 전체 명칭 | `"부산광역시"` |
| 시군구 | 시·군·구 명칭 | `"강서구"` |
| 읍면동 | 읍·면·동 명칭 | `"명지동"` |
| 본번 | 지번 앞 번호 (133-3이면 133) | `"133"` |
| 부번 | 지번 뒷 번호 (133-3이면 3), 없으면 빈칸 | `"3"` 또는 `""` |
| 건물명 | 건물 이름 (공식 등록명 앞부분) | `"리첸시아용산"` |
| 건물동 | 동 이름 (A동은 "에이동"으로 입력 가능) | `"322동"`, `"에이동"` |
| 층 | 층수 (지하는 "지하1층" 형식) | `"1층"`, `"지하1층"` |
| 호 | 호수 | `"104호"`, `"317호"` |
| 사업자등록번호 | 하이픈 없이 입력, 없으면 빈칸 | `"4823100133"` 또는 `""` |

### 2단계: 실행

명령 프롬프트(cmd)에서 프로그램 폴더로 이동 후 실행:
```
node loan-review.mjs 111.json
```

- 크롬 브라우저가 자동으로 열리며 6개 사이트를 순서대로 조회합니다
- 완료까지 약 **2~3분** 소요됩니다
- 브라우저를 건드리지 말고 기다려 주세요

### 3단계: 결과 확인

실행 완료 후 프로그램 폴더에 아래 파일이 생성됩니다:

| 파일 | 설명 |
|------|------|
| `111.docx` | 최종 Word 보고서 |
| `111_1_기준시가.png` | 상가 기준시가 캡처 |
| `111_2_매각가율.png` | 매각가율 캡처 |
| `111_3_사업자상태.png` | 사업자등록상태 캡처 |
| `주소지이름(토지).png` | 토지이용계획 캡처 |
| `주소지이름(건축물).png` | 건축물정보 캡처 |
| `111_5_지가변동률.png` | 지가변동률 캡처 |
| `111_6_공시지가.png` | 개별공시지가 캡처 |

## ⚠️ 주의사항

- 실행 중 마우스로 브라우저를 조작하지 마세요
- 인터넷 연결이 필요합니다
- 홈택스 점검 시간(보통 매일 자정~06시)에는 실행이 안 될 수 있습니다
- 사업자등록번호가 없는 경우 빈칸(`""`)으로 두면 해당 항목은 빈 화면으로 저장됩니다

## 🔧 오류 발생 시

오류가 발생하면 콘솔에 `❌ 오류:` 메시지가 표시됩니다.
오류가 발생해도 그 이전까지 캡처된 파일로 Word 문서가 생성됩니다.

자주 발생하는 오류:

| 오류 | 원인 | 해결 |
|------|------|------|
| 법정동 선택 실패 | 읍면동 이름이 다름 | 실제 등기부 상 읍면동명 확인 |
| 건물 링크 없음 | 건물명 또는 번지가 다름 | 홈택스에서 직접 확인 후 수정 |
| timeout 오류 | 사이트 응답 느림 | 재실행 |
